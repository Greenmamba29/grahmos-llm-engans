# Phase 2 Manual Branding Guide

Step-by-step guide for applying GrahmOS branding manually in Webflow Designer.

## 🎨 Brand Colors

- **Primary Blue**: `#2563EB`
- **Text Dark**: `#1F2937`
- **Success Green**: `#10B981`
- **Warning Amber**: `#F59E0B`
- **Error Red**: `#EF4444`

## 📝 Step-by-Step Instructions

### Step 1: Update Color Palette

1. Open Webflow Designer
2. Go to **Style Panel** → **Colors**
3. Create/Update colors:
   - Primary: `#2563EB`
   - Secondary: `#1F2937`
   - Success: `#10B981`
   - Warning: `#F59E0B`
   - Error: `#EF4444`

### Step 2: Update Typography

1. Go to **Style Panel** → **Typography**
2. Set font family to **Inter** (or system sans-serif)
3. Update heading styles:
   - H1: 3rem, Bold
   - H2: 2.25rem, Bold
   - H3: 1.875rem, Semi-bold
   - H4: 1.5rem, Semi-bold

### Step 3: Update Home Page

1. Select home page in Navigator
2. Update page title: "GrahmOS Directory - Discover Innovation"
3. Update meta description
4. Apply primary color to main CTA buttons
5. Update text colors to use Text Dark (`#1F2937`)

### Step 4: Update Components

1. **Buttons**: Apply primary color to primary buttons
2. **Links**: Use primary color for links
3. **Cards**: Add subtle borders using secondary color
4. **Forms**: Style inputs with primary color focus states

### Step 5: Save & Publish

1. Click **Publish** in top right
2. Select pages to publish
3. Confirm publication

## ⏱️ Estimated Time

- Colors: 15 minutes
- Typography: 20 minutes
- Home Page: 30 minutes
- Components: 45 minutes
- **Total: ~2 hours**

## 💡 Tips

- Use **Combo Classes** for reusable styles
- Create **Symbols** for repeated components
- Use **CMS** for dynamic content
- Test on mobile viewport
